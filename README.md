# 🤖 CryptoBot V9.8.0 — بوت تداول Binance مع لوحة تحكم عربية

بوت تداول آلي لمنصة **Binance Spot** يعمل على فريم 15 دقيقة، مزوّد بسبع استراتيجيات إشارات،
فلاتر تأكيد متعددة الطبقات، نظام إدارة صفقات ديناميكي (رحلة التداول)، ولوحة تحكم ويب عربية كاملة.

> ⚠️ **تحذير مخاطرة:** تداول العملات الرقمية عالي المخاطر. هذا المشروع لأغراض تعليمية وتشغيلية شخصية،
> وليس نصيحة استثمارية. ابدأ دائمًا بالتداول التجريبي (التداول الحقيقي معطّل افتراضيًا عند كل إعادة تشغيل).

## ✨ الاستراتيجيات المفعّلة (7 استراتيجيات)

| # | الاستراتيجية | النوع | ملاحظات |

| 1 | MACD + EMA | اتجاهي | عبور MACD صعودًا + قوة هيستوغرام + ADX |

| 3 | EMA + RSI Cross | اتجاهي | تقاطع EMA9/EMA21 مع RSI قوي |

| 5 | BB Squeeze Breakout | اختراقي | انضغاط النطاق ثم اختراق بحجم |
| 6 | Bullish Momentum | زخم | قمم/قيعان صاعدة + ADX قوي |
| 7 | S/R Breakout (Enhanced) | اختراقي | اختراق مقاومة مُختبرة + تجنب الاختراقات الكاذبة |

## 🔧 التحسينات في نسخة V9.8.0

### إصلاحات أخطاء
- **حذف الدالة المكررة** `check_price_peak_filter` (كانت معرّفة مرتين بشكل متطابق).
- **إصلاح تحذيرات pandas الحديثة**: `fillna(method='ffill')` → `.ffill()`، و `astype(errors='ignore')` → تحويل آمن للأعمدة الرقمية فقط.

### استراتيجيات وفلاتر (كانت معرّفة لكن غير مفعّلة في الكود الأصلي)
- ✅ **تأكيد الترند على فريم الساعة (HTF Confirmation)**: تُرفض الإشارات الاتجاهية/الاختراقية
  إذا لم يكن الترند صاعدًا على فريم 1h — مع **كاش 15 دقيقة** لكل عملة لتقليل استهلاك API.
- ✅ **فلتر تجنب القمم**: يُطبق على الاستراتيجية الارتدادية فقط (BB+Stoch) لمنع الشراء عند قمة آخر 24 ساعة
  (لا يُطبق على استراتيجيات الاختراق لأنها تشتري عند القمم بطبيعتها).
- ✅ **فلتر الزخم قصير الأجل**: متاح كخيار إضافي صارم عبر متغير البيئة
  `USE_SHORT_TERM_MOMENTUM_FILTER` (معطّل افتراضيًا).
- ✅ **أرضية الهدف الأدنى (MIN_PROFIT_PERCENT)**: أصبحت مفعّلة فعليًا — لا يتم تمديد هدف
  الرحلة إلى قيمة أقل من الحد الأدنى للربح المستهدف.

### إدارة مخاطر
- 🛡️ **قاطع حماية يومي (Daily Loss Circuit Breaker)**: عند تجاوز الخسارة المحققة اليومية
  الحد `DAILY_MAX_LOSS_USDT` (افتراضي 20 USDT) يتوقف فتح صفقات جديدة حتى بداية اليوم التالي (UTC).
- 🛡️ **بيع آمن عند الإغلاق**: لا يعود يبيع كامل رصيد العملة تلقائيًا — يبيع الكمية المرتبطة بالصفقة فقط
  (مع تسامح 5%) لتجنب بيع أرصدة خارجية مملوكة لنفس العملة.

### أداء على الخطة المجانية (512MB RAM)
- 📉 **تقليل حمل المسح**: سجل 30 يومًا افتراضيًا بدلًا من 90 (كافٍ تمامًا لكل المؤشرات،
  قابل للضبط عبر `SIGNAL_GENERATION_LOOKBACK_DAYS`).
- ⚡ **كاش ATR للوقف المتحرك**: جلب الشموع لكل صفقة مرة كل 60 ثانية بدلًا من كل تحديث سعر.
- ⚡ تحديث الأسعار كل ثانيتين بدلًا من كل ثانية.

### بنية تحتية وأمان
- 🔐 **حماية لوحة التحكم بـ Basic Auth**: تُفعّل تلقائيًا عند ضبط `DASHBOARD_USERNAME` و `DASHBOARD_PASSWORD`
  (لوحة التحكم عامة على Render — الحماية ضرورية لأن أي زائر كان يستطيع سابقًا تشغيل التداول الحقيقي!).
- 🧠 **Redis أصبح اختياريًا**: عند غياب Redis يتحول البوت تلقائيًا لبديل في الذاكرة
  (كان ينهار ويخرج سابقًا) — مناسب تمامًا للخطة المجانية.
- ❤️ **نقطة فحص صحة `/health`** للمراقبة و UptimeRobot (مستثناة من المصادقة).
- ⚙️ إعدادات جديدة قابلة للضبط عبر متغيرات البيئة دون تعديل الكود.

## 🚀 النشر على Render (خطة مجانية — منطقة فرانكفورت)

### المتطلبات الأساسية
1. **قاعدة بيانات PostgreSQL مجانية** — أنشئ واحدة على [Neon.tech](https://neon.tech) (أو Supabase):
   - أنشئ Project جديد (اختر منطقة قريبة من أوروبا مثل Frankfurt).
   - انسخ رابط الاتصال بصيغة `postgresql://user:pass@host/db?sslmode=require`.
2. **مفاتيح Binance API**: من حساب Binance → API Management → أنشئ مفتاحًا مع صلاحية
   **Enable Spot Trading** فقط (لا تسحب/إيداع). احفظ `API Key` و `Secret`.
3. (اختياري) **تليجرام**: أنشئ بوتًا عبر @BotFather للحصول على Token، واعرف Chat ID عبر @userinfobot.
4. (اختياري) **Redis مجاني** من [Upstash](https://upstash.io) — أو اتركه فارغًا لاستخدام بديل الذاكرة.

### خطوات النشر
1. ارفع هذا المستودع إلى GitHub (موجود مسبقًا: `crypto-bot-v9`).
2. في [Render Dashboard](https://dashboard.render.com): **New + → Blueprint** → اختر مستودع `crypto-bot-v9`.
   - ملف `render.yaml` سيضبط تلقائيًا: **الخطة المجانية، منطقة Frankfurt، أمر البناء والتشغيل، ونقطة الفحص `/health`**.
3. بعد الإنشاء، افتح **Environment** وأضف متغيرات البيئة من الجدول أدناه.
4. انتظر اكتمال النشر، ثم افتح الرابط `https://<اسم-الخدمة>.onrender.com` — ستظهر لوحة التحكم (ستُطلب بيانات الدخول إن فعّلت الحماية).
5. راقب سجلات Logs: يجب أن ترى `✅ [قاعدة البيانات]` و `✅ [التحقق من الرموز]` وبدء حلقة المسح.
6. عند التأكد من عمل كل شيء: فعّل **التداول الحقيقي** من زر التبديل في اللوحة (على مسؤوليتك).

### متغيرات البيئة

| المتغير | إلزامي؟ | القيمة / الوصف |
|---------|---------|-----------------|
| `BINANCE_API_KEY` | ✅ | مفتاح Binance API |
| `BINANCE_API_SECRET` | ✅ | السر الخاص بمفتاح Binance |
| `DATABASE_URL` | ✅ | رابط PostgreSQL (Neon/Supabase) مع `sslmode=require` |
| `REDIS_URL` | ➖ | رابط Redis خارجي — اتركه فارغًا لاستخدام بديل الذاكرة |
| `TELEGRAM_BOT_TOKEN` | ➖ | توكن بوت تليجرام للإشعارات |
| `TELEGRAM_CHAT_ID` | ➖ | معرف المحادثة لاستقبال الإشعارات |
| `DASHBOARD_USERNAME` | 🔐 موصى | اسم مستخدم لوحة التحكم (يُفعّل الحماية) |
| `DASHBOARD_PASSWORD` | 🔐 موصى | كلمة مرور لوحة التحكم |
| `DAILY_MAX_LOSS_USDT` | ➖ | حد الخسارة اليومي (افتراضي `20`) |
| `SIGNAL_GENERATION_LOOKBACK_DAYS` | ➖ | أيام البيانات التاريخية (افتراضي `30`) |
| `MAX_OPEN_TRADES` | ➖ | أقصى عدد صفقات مفتوحة (افتراضي `5`) |
| `USE_HTF_CONFIRMATION` | ➖ | تأكيد الترند على فريم الساعة (افتراضي `True`) |
| `USE_SHORT_TERM_MOMENTUM_FILTER` | ➖ | فلتر زخم إضافي صارم (افتراضي `False`) |
| `PYTHON_VERSION` | ➖ | `3.11.9` (يضبطها render.yaml تلقائيًا) |
